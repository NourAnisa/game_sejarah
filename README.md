# 🏛️ Laskar Waktu: Petualangan Sejarah Nusantara

> **Game Interaktif Edukasi Sejarah Indonesia Melintasi Era Kejayaan Kerajaan, Perlawanan Kolonialisme, Kebangkitan Nasional, hingga Detik-Detik Proklamasi Kemerdekaan 17 Agustus 1945.**

🌐 **Live Demo (GitHub Pages):** [https://nouranisa.github.io/game_sejarah/](https://nouranisa.github.io/game_sejarah/)

---

## 🌟 Fitur Utama Permainan

1. **🧭 Ekspedisi Lini Masa (Story Mode / Visual Interactive Novel)**
   - Menjelajahi 5 Era Akbar Sejarah Indonesia:
     - **Era 1:** Kejayaan Kerajaan Maritim & Agraris (Kutai, Sriwijaya, Majapahit & Sumpah Palapa Gajah Mada).
     - **Era 2:** Perlawanan Kedaerahan Terhadap Kolonialisme & Monopoli VOC (Sultan Hasanuddin, Pangeran Diponegoro, Pattimura, Imam Bonjol, Cut Nyak Dhien).
     - **Era 3:** Fajar Kebangkitan Nasional (Boedi Oetomo, Ki Hajar Dewantara, Sumpah Pemuda 1928, Lagu Indonesia Raya).
     - **Era 4:** Detik-Detik Proklamasi Kemerdekaan 1945 (Rengasdengklok, Rumah Laksamana Maeda, Sayuti Melik, Soekarno-Hatta).
     - **Era 5:** Mempertahankan Kedaulatan & Diplomasi (Pertempuran 10 November Surabaya, Bandung Lautan Api, Serangan Umum 1 Maret, KMB).
   - Dialog interaktif dengan tokoh bangsa, pengambilan keputusan taktis, dan penjelasan historis mendalam.

2. **⏳ Susun Garis Waktu (Timeline Logic Puzzle)**
   - Teka-teki menyusun kartu-kartu peristiwa penting secara kronologis (dari masa terlama hingga terkini).
   - Dilengkapi sistem validasi instan, fakta tarikh sejarah, dan ringkasan kronologi.

3. **🔍 Detektif Tokoh & Artefak (Mystery Dossier Quiz)**
   - Menganalisis berkas rahasia arsip pahlawan dengan 3 tingkat petunjuk bertahap (Gelar, Pusaka/Kutipan, Peristiwa).
   - Dilengkapi siluet misterius dan biografi ringkas pahlawan pejuang kemerdekaan.

4. **🗺️ Atlas Nusantara Interaktif**
   - Eksplorasi 7 gugusan kepulauan nusantara (Sumatera, Jawa, Kalimantan, Sulawesi, Bali & Nusa Tenggara, Maluku, Papua).
   - Mengungkap kerajaan bersejarah lokal, tokoh pejuang daerah, dan peninggalan budaya masing-masing pulau.

5. **📜 Piagam Kehormatan Resmi (Certificate Generator)**
   - Generator sertifikat kelulusan berbasis Canvas HTML5 dengan ornamen batik nusantara dan stempel emas.
   - Nama pemain dapat disesuaikan dan diunduh langsung sebagai file gambar PNG beresolusi tinggi atau dicetak ke format PDF.

6. **🎵 Synthesizer Audio Nusantara (Zero-Dependency Web Audio API)**
   - Musik latar (BGM) suasana tradisional nusantara berbasis tangga nada pentatonik (Slendro & Pelog) tanpa perlu download file MP3 eksternal.
   - Efek suara sintetis (SFX) interaktif: chime kemenangan, fanfare kenaikan level, suara klik, dan animasi partikel confetti.

7. **📱 Desain Modern & Responsif**
   - Mendukung penuh tampilan smartphone, tablet, laptop, hingga proyektor interaktif ruang kelas.

## 🚀 Cara Menjalankan Secara Lokal

Cukup buka berkas `index.html` langsung di peramban web mana saja (Google Chrome, Edge, Safari, Firefox) tanpa perlu instalasi server atau kompilasi:

```bash
# Clone repositori
git clone https://github.com/NourAnisa/game_sejarah.git

# Masuk ke direktori
cd game_sejarah

# Buka di browser
start index.html # (Di Windows)
# atau: open index.html (Di macOS)
```

---

## 🛠️ Teknologi yang Digunakan

- **HTML5 & Vanilla JavaScript ES6+**
- **Tailwind CSS (CDN)** untuk antarmuka modern & glassmorphism
- **Web Audio API** untuk sintesis musik latar dan efek suara interaktif
- **HTML5 Canvas 2D** untuk generator sertifikat dan efek selebrasi confetti
- **Local Storage API** untuk penyimpanan progres, XP, permata, dan medali pemain
